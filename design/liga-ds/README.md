# Liga design system

Design system for the Liga app (standalone league app built from Office 8-Ball).
Run: `python3 -m http.server 4620` in this folder, open http://localhost:4620

- `tokens.css`: primitives, semantic tokens (dark default, light), scales
- `components.css`: every component, tokens only
- `tokens.json`: same values for the Expo app
- `index.html`, `page.css`, `page.js`: the showcase page only
