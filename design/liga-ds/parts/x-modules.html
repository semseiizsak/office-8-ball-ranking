Do
  • Apply a switch at once and confirm with a toast, no save button for a single toggle.
  • Name the missing module and offer a one tap fix.
  • Keep the data when a module goes off, it comes back when switched on again.
Don't
  • Hide a module that cannot be used yet, people never find it again.
  • Grey out Pro modules without telling what unlocks them.
  • Ask for a reason when an admin turns something off.
